Why believe the numbers

Three independent tiers of evidence

The accuracy claim is defended three ways — a live product run on real imagery, a fresh download reconstructed end-to-end, and a ground-truth benchmark with honest, gauge-free metrics.

01

Live product run — 50 real geotagged aerial photos

Ingested through the running app (COLMAP engine), georeferenced from GPS, rendered in the 3D workspace with provenance colouring and in-browser measurement.

50/50 keyframes · 9,030 pts · 0.223 px reproj · GPS-scaled · align 1.74/1.01 m · distance tool 38.146 m

02

Fresh download, reconstructed this session

A contiguous strip of OpenDroneMap imagery pulled at demo time and pushed straight through the pipeline — proving the path runs on data it had never seen, not a curated fixture.

Waterbury video-survey — 35/50 cams · 5,780 pts · 0.306 px · buildings + parking lot. Aukerman aerial — 21/28 · 0.99 px. A real DJI video was also ingested straight from its .SRT per-frame GPS.

03

Ground-truth benchmark — synthetic scene with known geometry

The evaluation harness scores the pipeline against true camera poses, a true point cloud and known reference distances. Ground-truth poses are never fed in; scale comes from synthesised drone-grade noisy GPS.

ATE 0.24 m · scale error 0.35% · dimensional error 4.70% (90-frame synthetic scene, gauge-free metrics).

The wedge

Measurement safety, not a pretty dashboard

Honesty rules built into the product

  • Every point carries provenance — observed-high, observed-low, AI-inferred, dynamic-excluded or unobserved. Measurements use high-confidence observed geometry unless you opt in.
  • Alignment residual ≠ accuracy. The GPS-consistency residual is reported separately and never dressed up as independent accuracy.
  • Scale is labelled by source — ordinary GPS is metre-level; RTK/PPK is labelled as such. Centimetre accuracy is never claimed without measured ground truth.
  • Capabilities are probed live — the UI only claims engines that are actually installed.
Reproduce it

Run the whole thing yourself

# reconstruction + backend (serves the built UI at :8000)
pip install -e reconstruction
cd backend && uvicorn app.main:app        # http://127.0.0.1:8000

# ground-truth benchmark — no download needed
python -m eval.run_eval --self-test

# score real datasets (auto-detects ODM / TartanAir / ETH3D / TUM)
python -m eval.run_eval --root eval_data
