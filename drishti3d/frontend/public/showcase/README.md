# Homepage research scene

`preview.bin` is a deterministic sample of the existing files
`public/prototype/dense.ply` and `public/prototype/measured.ply`. It preserves
their coordinates and RGB values, and adds a provenance byte per point.
It is a lightweight visual preview, never an input to measurements.

Rebuild from the frontend directory with `python3 scripts/build-preview.py`.
The preview contains at most 24,000 dense and 8,000 triangulated points.
Each record is 16 bytes: little-endian float32 XYZ, uint8 RGB, then uint8
provenance (0 = AI-assisted, 1 = triangulated). The scene uses relative scale.

`comparison.jpg` is an unchanged copy of
`docs/demo/drone_vs_3d_stills.jpg`; the video uses the existing
`public/prototype/reference.mp4`. Original footage: Gymnasium Neubiberg,
Wikimedia Commons, CC BY-SA, as recorded in `docs/demo/README.md`.
The reconstruction, sampling, and comparison were generated by Drishti3D.
The evidence diagram on the homepage is separately labelled as a concept
diagram; it is not presented as measured geometry.
