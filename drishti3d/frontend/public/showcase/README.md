# Homepage scene

The homepage shows the whole of **DJI_1003**: 11 min 18 s of native 1080p DJI
video with per-frame SRT GPS, reconstructed with COLMAP and dense stereo
(80/80 keyframes). It is drawn with WebGL, from the south, the river and its
bridges across the middle and the downtown towers beyond.

Two sources, one frame:

* `preview.bin` -- a uniform 150,000-point sample, painted first. It is the
  whole scene wherever the mission itself is absent (a fresh clone, no backend).
* Every point -- when this installation has the mission (`project_id` in
  `preview.json`), the page streams `/api/projects/<id>/model.bin`: 3,124,856
  reconstructed points plus 540,776 inferred-fill points (open water, holes),
  58.7 MB. Nothing that large lives in the repository.

`preview.json` records the source project, the sampled class counts, the
default view, and `origin_enu` / `metres_per_unit`: the transform the sample
was built with, which the page applies to the streamed cloud so both land in
the same place. Rebuild from the `drishti3d` directory:

```bash
.venv/bin/python frontend/scripts/build-preview.py            # whole DJI_1003
.venv/bin/python frontend/scripts/build-preview.py --project <id> [--box E0 E1 N0 N1]
```

Each `preview.bin` record is 16 bytes, little endian: x, y, z float32 (east,
up, north, relative to `origin_enu` and divided by `metres_per_unit`), then r,
g, b uint8 and the provenance code uint8 (`drishti_recon.provenance.Provenance`:
0 observed high, 1 observed low, 6 inferred fill). The preview is a picture;
it is never an input to measurement.

Source footage: AirLock (WACV 2026), CC BY 4.0, attribution required (see
`MODEL_LICENSE_MANIFEST.md`); the homepage shows the credit line from
`preview.json`. The reconstruction and sampling were generated by Drishti3D.

`comparison.jpg` is an unchanged copy of `docs/demo/drone_vs_3d_stills.jpg`,
the poster of the Gymnasium example further down the homepage; that example
and the research lab (`/prototype`) still use the Gymnasium Neubiberg footage
(Wikimedia Commons, CC BY-SA).
